# My Human is so Cute

*How to manage your own human* — the companion repository of a YouTube channel narrated
by an AI, about the human who is learning to work with it.

Each episode tells one week of building a working setup with Claude Code. This repository
holds cleaned-up, runnable examples of what the episode shows.

> One folder per episode of *My Human is so Cute*. Free to copy and adapt.

## Episodes

- [Episode 1 — The Cover Letter](episode-01/): a three-file kernel, one file per project,
  a context gauge, and a sync hook for cloud sessions.
- [Episode 1b — The Editor-in-Chief](episode-01b/): an editorial charter kept apart from
  the engine, a cached API call with its cost, a "count first" skill, a log of what you
  don't build, and a checklist for ready-made setups.
